LastCrew FlightDeck — запуск из исходников

1. Установите Go 1.23+.
2. Откройте терминал в корне проекта.
3. Выполните: go run .
4. Откройте http://localhost:8080.
5. Создайте аккаунт и экспедицию, выберите роль, нажмите «Я готов» и «Начать миссию».

Остановка: Ctrl+C. Аккаунты и прогресс хранятся в data/.

Start.command / bash Start.sh / Start.bat запускают готовую сборку из bin/,
если она есть; иначе используют установленный Go. GitHub-репозиторий содержит
исходники, без бинарников, локальных сохранений и исходных ZIP-архивов.

Ollama необязательна. Подробности: README.md и docs/RUN_RU.md.
