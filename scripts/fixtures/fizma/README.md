# FIZMA reference fixtures

These four files were extracted verbatim from the supplied `FIZMA.zip` for
`scripts/test-fizma-entry.mjs`. They are test inputs, not application code.
`manifest.json` records their SHA-256 hashes. Font hashes and provenance are in
`web/css/fonts/sources.json`; they were verified against the archive when these
fixtures were extracted.

The test runs with Node alone. The original archive and its build dependencies
are not required in a source checkout.
